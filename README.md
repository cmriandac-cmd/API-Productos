# API RESTful de Productos

## Descripción

API RESTful desarrollada con Node.js y Express para gestionar productos mediante operaciones CRUD.

La API permite crear, consultar, actualizar y eliminar productos utilizando solicitudes HTTP y respuestas en formato JSON.

Los datos se almacenan de forma persistente en un archivo JSON.

---

## Tecnologías utilizadas

- Node.js
- Express.js
- JavaScript
- JSON
- Postman
- Git y GitHub

---
